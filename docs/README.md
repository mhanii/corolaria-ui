# Corolaria UI Documentation

Welcome to the internal documentation for the Corolaria UI project.

## Directory Structure

- [Chat Service](./chat_service.md): Architectural overview of the chat system, SSE implementation, and useChatStream hook.

## Key Concepts

- **SSE (Server-Sent Events)**: The core technology for real-time AI responses.
- **Workflow vs. Agent Mode**: Two distinct interaction patterns for different AI capabilities.
- **Artifacts**: Complex documents generated by the AI that persist across the conversation.
